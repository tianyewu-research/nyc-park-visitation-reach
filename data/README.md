| Source | Used for | Access |
|---|---|---|
| Advan Weekly Patterns, 2023 (NYC park POIs) | Visits by visitor home block group, dwell time | Licensed; academic access via Dewey |
| ACS 2023 5-year estimates (B01003, B19013, B02001) | Population, income, race/ethnicity | Public, data.census.gov |
| TIGER/Line 2023 block groups | Geography | Public, U.S. Census Bureau |
| NYC Parks Properties; NYC Borough Boundaries | Park polygons | Public, NYC Open Data |
| NYC Parks recreation facilities; public park restrooms | Park attributes | Public, NYC Open Data |
| Trust for Public Land ParkServe | Park canopy attribute | Public, ParkServe download |
| EPA National Walkability Index; Smart Location Database | Walkability and transit | Public, U.S. EPA |
